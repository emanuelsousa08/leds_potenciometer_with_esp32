# Controlando LEDs com Potenciômetro usando ESP32

Este projeto demonstra como controlar a intensidade de LEDs utilizando um potenciômetro e um ESP32. O experimento foi desenvolvido e testado no simulador online [Wokwi](https://wokwi.com/).

## Descrição do Projeto

- **Microcontrolador**: ESP32
- **Componentes**:
  - Potenciômetro
  - LEDs
  - Resistores
- **Funcionamento**: O potenciômetro controla a intensidade dos LEDs, variando a tensão analógica que é lida pelo ESP32. O microcontrolador, então, ajusta o brilho dos LEDs com base nos valores obtidos.

## Como Executar no Wokwi

1. Acesse o [Wokwi](https://wokwi.com/).
2. Importe ou recrie o circuito usado neste projeto.
3. Copie o código do projeto para o editor do simulador.
4. Execute a simulação e ajuste o potenciômetro para observar as mudanças na intensidade dos LEDs.
